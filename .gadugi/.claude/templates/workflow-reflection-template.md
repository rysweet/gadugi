# Workflow Reflection Template

This template is used for workflow phase reflection and analysis.

## Variables Available:
- {phase_name}: Current workflow phase name
- {phase_status}: Phase execution status
- {start_time}: Phase start timestamp
- {end_time}: Phase completion timestamp
- {duration}: Phase execution duration
- {metrics}: Performance metrics for the phase
- {issues}: Any issues encountered during execution
- {success_criteria}: Phase success criteria validation

## Reflection Questions:
1. Did the phase complete successfully?
2. Were the success criteria met?
3. What challenges were encountered?
4. What improvements could be made?
5. Are there any blockers for subsequent phases?

## Usage:
This template is used by the workflow reflection system to capture
phase-level insights and learnings for continuous improvement.
